## 🏗️ System Overview

The Hospital & Patient Management System is a full-stack application consisting of:

| Component | Tech | Repository |
|-----------|------|------------|
| Mobile App | Flutter | [hospital-app-mobile](https://github.com/zuhudo/hospital-app-mobile) |
| Backend API | Go + Fiber | [hospital-app-backend](https://github.com/zuhudo/hospital-app-backend) |
| Public Website | Astro | [hospital-app-web](https://github.com/zuhudo/hospital-app-web) |
| Admin Dashboard | React + Vite | [hospital-app-dashboard](https://github.com/zuhudo/hospital-app-dashboard) |
